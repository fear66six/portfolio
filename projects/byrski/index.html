ByrSki 票务平台

后端开发 · 仓库 ByrSki-Official/ByrSki

翻开产品画册

要解决的问题

ByrSki 是面向高校滑雪活动报名和票务的线上平台，覆盖活动发布、购票订单和优惠券。优惠券要能创建、领取、按条件使用，并在退款和过期后保持状态正确。

我负责什么

我设计并实现优惠券模块，覆盖创建、启停、领取、筛选、核销、退款返还和过期处理，再把它接进多人票订单的计价。

关键做法

  • 优惠有固定金额和折扣两种。使用条件包括商品、活动模板、雪场、订单金额和参与人数。
  • 订单计价统一算原价、优惠金额和实付金额。退款时按退款时间和优惠券有效期，把券恢复为可用，或者标成过期。
  • 领取请求用 Redis SETNX 和 TTL 做互斥。发放记录生成安全签名，定时任务维护优惠券状态。补充了优惠券校验、订单集成和多人下单测试。
  • 服务是 Java 17 和 Spring Boot 3，数据用 MySQL、MyBatis-Plus 和 Redis。

结果

平台已真实上线，服务约 2000 名用户。
